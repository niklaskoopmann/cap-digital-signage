Xibo installation on docker: https://account.xibosignage.com/docs/setup/xibo-for-docker#content-docker-on-linux

This repository bundles a local Xibo Docker setup under `xibo-docker-4.4.2/`.
Use `xibo-docker-4.4.2/docker-compose.yml` as the compose file for the included installation.

The player notes live in `xibo-player/Readme.md`.
